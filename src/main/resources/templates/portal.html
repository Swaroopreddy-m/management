System Authorization Hierarchy

Each administrative level can manage only the resources and permissions authorized by the level above it. Page registration does not grant authorization. Permissions are granted via Super Admin approvals and distributed through organization permission groups.

DEVELOPER (Application Technical Configuration & Page Registry) │ ▼ SUPER ENTITY (Holding Group Governance Scope) │ ▼ SUPER ADMIN (Organization Management & Centralized Page Approvals / Revocation) │ ▼ ORGANIZATION (Tenant Data-Isolation Boundary) │ ▼ ORGANIZATION ADMIN (Entity Management, User Allocation & Group Permissions) │ ├─► Organizational Entities (Branches, Departments, Stores) │ ▼ PERMISSION GROUPS (Group-Action Combinations: VIEW, CREATE, UPDATE, DELETE, EXPORT) │ ▼ USERS (Effective Access Evaluated Server-Side on Every Operation)
